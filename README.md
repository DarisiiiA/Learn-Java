# Java Trail

A beginner-friendly Java learning app built with HTML, CSS, and vanilla JavaScript. Includes 15 short lessons, answer explanations, a statement exercise, searchable reference notes, four practice projects, and progress saved locally in your browser.

## Run

From this directory, run `npm start` (requires Python 3), then open port 3000 in a browser. Alternatively, open `index.html` directly. No installation, backend, or API key is needed. Fonts use Google Fonts with system fallbacks.

`npm run check` checks JavaScript syntax. `node --test app.test.cjs` runs interaction checks.

The app does not execute arbitrary Java. Multiple-choice questions and the clearly labeled statement practice provide instant feedback. Practice projects are intended to be compiled with a local JDK. Browser progress is device-specific and can be lost when browser data is cleared.
